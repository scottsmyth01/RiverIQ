BASIC ROUTING 

What routes you now have
1 - Register

POST /api/auth/register

Body:
{
  "name": "Scott Smyth",
  "username": "scott",
  "email": "scott@example.com",
  "password": "123456"
}

2 - Login

POST /api/auth/login

Body:
{
  "email": "scott@example.com",
  "password": "123456"
}

3 - Get current user

GET /api/auth/me

Header:
Authorization: Bearer YOUR_JWT_TOKEN
How to test it in Postman / Thunder Client
Register
Method: POST
URL: http://localhost:5000/api/auth/register

Body → JSON
{
  "name": "Scott Smyth",
  "username": "scott",
  "email": "scott@example.com",
  "password": "123456"
}

If successful, you’ll get back the user info + token.
